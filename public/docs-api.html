Documentation API

API publique de Nostr Map

Cette documentation décrit la partie publique en lecture seule de l'API de Nostr Map. Elle est pensée pour la recherche de profils, la consultation de fiches publiques et la découverte automatisée.

Base URL https://nostrmap.fr Catalogue /.well-known/api-catalog Spec /openapi/public-api.json

Portée

La version publique agents v1 expose uniquement des endpoints de lecture. Les opérations d'écriture ou d'administration ne font pas partie de ce catalogue.

L'authentification applicative actuelle de Nostr Map repose sur des signatures Nostr (NIP-98) et un JWT interne. Le site ne publie pas actuellement de découverte OAuth/OIDC.

GET /api/search.php

Recherche de profils publics ou chargement de la grille d'accueil.

Paramètres utiles

  • q : texte de recherche, optionnel
  • limit : nombre maximum de résultats, optionnel
  • sort : recent, actifs, populaires, random
  • offset : pagination pour la grille
  • seed : graine numérique pour sort=random

Exemple

GET /api/search.php?q=alice&limit=5

Réponse type

{
  "results": [
    {
      "npub": "npub1...",
      "slug": "alice",
      "cached_name": "Alice",
      "cached_nip05": "alice@example.com",
      "verified_platforms": ["mastodon"]
    }
  ]
}

GET /api/profile.php

Retourne un profil public et ses liens associés à partir d'un slug.

Paramètre requis

  • slug : identifiant public du profil

Exemple

GET /api/profile.php?slug=alice

Réponse type

{
  "profile": {
    "npub": "npub1...",
    "slug": "alice",
    "cached_name": "Alice"
  },
  "links": [
    {
      "platform": "mastodon",
      "verified": true,
      "url": "https://example.social/@alice"
    }
  ]
}

GET /api/status.php

Endpoint de statut minimal pour la découverte et la supervision légère. Il confirme que l'application répond et que le check base de données passe. 

{
  "status": "ok"
}

Hors périmètre de cette v1

  • Authentification et émission de JWT
  • Ajout ou vérification de liens sociaux
  • Contact, proposition de profil et signalement
  • Administration et modération
  • OAuth/OIDC, OAuth Protected Resource Metadata, MCP, WebMCP
